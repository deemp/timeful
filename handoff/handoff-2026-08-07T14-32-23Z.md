## Important Decisions

- **Cell-state source (new, replaces prior handoff step 1):** record the hovered cell's `TimedCellState` in a parallel `curTimeslotCellState` ref owned by `useAvailabilityData`, set at hover time inside `showAvailability`, mirroring how `curTimeslotInactive` is already managed. The view model and `RespondentsList` only consume it.
  - Rationale: `showAvailability` (`useAvailabilityData.ts:711-734`) updates `curTimeslot` only for cells with a real slot; for inactive cells it calls `markCurTimeslotInactive()` (`:699-709`) which leaves `curTimeslot` stale, and grid `mouseleave` resets it to `{-1,-1}` (`useScheduleOverlapUI.ts:212-222`). Deriving the cell state from `curTimeslot` (old plan) would render plain grey instead of light-gray-stroke on first hover of an `enabled_inactive` cell.
  - Do NOT write inactive cells into `curTimeslot`: `showStickyRespondents` gates on `curTimeslot.row !== -1` (phone sticky panel, `useScheduleOverlapUI.ts:138`) and the grid hover highlight matches `curTimeslot` with a `!isDisabled` guard (`scheduleOverlapRendering.ts:346-355`); changing `curTimeslot` would ripple into both.
- `getTimedCellState` input added to `useAvailabilityData` is **optional**; when absent, inactive cells degrade to plain grey (previously accepted fallback). Existing test call sites (`useAvailabilityData.test.ts:70`, `regressionHarness.ts:31`, `scheduleOverlap.regressions.test.ts:606`) keep compiling.
- Absolute-column mapping: `getTimedCellState(row, maxDaysPerPage.value * page.value + col)` — mirrors `useTimedGridPresentation.ts:123-125`; `curTimeslot.col` is day-relative within a page.
- Behavior matrix unchanged from the prior handoff (avatar when no slot context; green/yellow/pink squares on an active slot; grey squares when `curTimeslotInactive`, `enabled_inactive` -> light-gray-stroke `#DFDFDF`, everything else -> gray `#BDBDBD`).
- Status precedence mirrors the CSV export (`useRespondentsCsvExport.ts:68-73`): availability-set hit = available; else `ifNeeded` hit = if needed; else unavailable.
- Use literal Tailwind class strings (static map) so the JIT keeps them; reuse exact legend classes from `ColorLegend.vue`.
- Keep the existing hover-to-select checkbox CSS swap untouched; the status square lives inside `.respondent-control__avatar`, so the existing swap hides it on row hover like the avatar.
